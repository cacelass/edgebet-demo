Acerca del Proyecto

Question Principal

Con datos publicos y un panel de casas donde se pueda ejecutar de verdad, existe una seleccion de partidos y mercados cuyo precio ejecutable bate al cierre justo de Pinnacle con margen suficiente para cubrir el coste de ejecucion?

Enfoque

LightGBM con objetivo Poisson, correccion Dixon-Coles, calibration por ECE, Kelly fraccional para sizing, y tracking de CLV como metrica primaria. Todo el codigo es open-source, pero los resultados de entrenamiento y los modelos de produccion estan en un repo privado.

Fuentes de Datos

  • Understat — xG partido a partido (gratis)
  • API-Football v3 — Lineups, injuries, stats, odds (gratis 100 req/dia)
  • football-data.co.uk — Resultados historicos, closing odds, arbitro (gratis)

Estado Actual

A 2026-08-06 la respuesta no esta demostrada. La evidencia apunta a que no hay edge explotable tras cubrir el coste de ejecucion (techo de ejecucion negativo en las cuentas reales).

No se apuesta dinero real en ninguna liga.

Que Mide el Sistema (en produccion)

CLV (Closing Line Value)

La metrica primaria. Mide si predijimos mejor que el cierre de Pinnacle. CLV > 0 = edge potencial.

CLV_log = ln(ejecutada / cierre_devigado)

Brier Score

Error cuadratico de probabilidades predichas vs resultados reales. Se usa ECE (Expected Calibration Error) para seleccion de modelo.

Delta Brier

Diferencia entre Brier del modelo y Brier del cierre de mercado. Positivo = el mercado predice mejor.

Kelly Sizing

Dimensiona apuesta con Kelly fraccional (Quarter Kelly en produccion: 25% del Kelly completo). Capado al 3% bankroll por apuesta.

Dixon-Coles

Correcion bivariada para partidos 0-0 y 1-0, que el Poisson estandar sobrestima.

Anti-Leakage

8 tests automatizados de anti-leakage: prefijo f_ obligatorio, rolling con .shift(1), Elo pre-partido, H2H pre-partido, TimeSeriesSplit temporal.

Mercados Cubiertos en Produccion

1X2 Over/Under 0.5-4.5 BTTS Asian Handicap Quarter Lines Corners O/U Score Exacto (Top-20)

Metodologia

1

Descarga de Datos

football-data.co.uk + Understat xG + API-Football (lineups, injuries, odds). Pipeline configurable por liga.

2

Construccion de Features

~245 features de contrato organizadas en 28 categorias: rolling stats, Elo MoV, fatiga, H2H, lineups, arbitro, home advantage dinamico, OA-xG, strength ratings, squad quality, set pieces, momentum EWMA...

3

Entrenamiento

LightGBM con objetivo Poisson, TimeSeriesSplit x 5 folds (assert temporal estricto), pesos temporales (semivida 180 dias), regularizacion L1+L2, early stopping por fold.

4

Prediccion

Lambdas home/away -> Poisson bivariada vectorizada + correccion Dixon-Coles + confianza (entropia de Shannon) + top-20 exactos con cuota justa + Asian Handicap completo.

5

Calculo de EV

Metodo Shin para probabilidades implicitas, EV con umbral ajustado por confianza, optimal_bet con score compuesto (EV - overround penalty), Kelly sizing con cap.

6

Tracking de CLV

Captura cuotas de ejecucion vs cierre de Pinnacle. t-test + IC 90% bootstrap + sign-flip test. Deteccion de degradation en ventana de 30 apuestas.

Configurar el Sistema Completo (local)

1. Instalacion

# Clonar repo (acceso restringido)
git clone https://github.com/cacelass/edgebet.git
cd edgebet

# Instalar dependencias
uv sync --extra dev --extra ml

2. Pipeline Basico

# Descargar datos
make data LEAGUES=laliga,premier

# Construir features
make features LEAGUES=laliga

# Entrenar modelo
make train LEAGUES=laliga

# Auditar
make audit LEAGUES=laliga

3. Predicciones

# Predicciones del dia con fixtures reales
make predict-today

# Predicciones manuales (sin API)
make predict-manual FIXTURES="Real Madrid;Barcelona"

# Escanar apuestas con edge
make scan DAYS=1 MIN_EDGE=0.07

Para obtener API-Football gratis: Registrate en api-football.com (plan gratuito: 100 requests/dia, sin tarjeta de credito). La clave la introduces en el demo de arriba.
